# Phase validation reports

This directory groups the Phase 1–17 validation reports. The corresponding
files directly under `code/evaluation/` are retained as canonical compatibility
paths because prior phase instructions, scripts, and evaluation links cite them.
On this Windows checkout the collection entries are NTFS hardlinks to those
canonical reports, so edits at either path update the same file. The ZIP
packager stores both paths as ordinary files for portable submission.

The source dataset CSVs remain in `dataset/`, the required submission CSV
remains at repository-root `output.csv`, and historical generated sample CSVs
are archived at repository-root `artifacts/csv/`.
